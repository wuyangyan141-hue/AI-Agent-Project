# RAG 升级说明

基于 main 的 `ec1b35b133add5bcdb37c56f4588a9c80f42398b`，按六个阶段调整，保留 Electron、React、FastAPI、LangChain、MCP、Skills、SQLite 及原有图片图集。

## 实现映射

1. **请求分流**：`knowledge/routing.py` 与 `/ws/chat` 区分普通聊天、资料问答、摘要、比较和学习工作流。普通聊天有明确入口；等待复习题不再全局捕获其他会话。
2. **检索**：`knowledge/retrieval.py` 结合关键词/BM25与可选语义向量。默认本地哈希向量只用于离线存储/记忆等旧接口兼容，课程检索必须有实际词项重合；哈希碰撞和文件名不能制造证据。删除自动加入其他文档关键词、返回开头片段的回退。词项、语义阈值分开配置。
3. **连续追问**：`knowledge_session_context` 保存资料范围与当前主题；省略范围时继承，显式null重置。有模型时结构化改写独立问题，不明确时追问；离线使用保存主题补充检索上下文。
4. **依据与引用**：`knowledge/grounding.py` 要求结论带逐字原文摘录。服务端检查来源与摘录，再独立检查相关性与支持程度。失败时展示有标记的原文或资料不足，不把无效生成结果当成答案。
5. **全文与比较**：遍历全部片段，按上下文预算分组、缓存、汇总。比较为每份选中资料分别取证，检查结果覆盖全部资料。离线导览与原文并列明确标记，不冒充模型综合结论。
6. **学习闭环与桌宠**：计划接入资料主题和证据，确认后才保存任务；复习题固定保存题目/参考答案/评分点/证据，评分基于原始快照。两个窗口共享会话、范围、消息、引用、警告、计划草稿和执行状态；超时或旧请求结果不会接入新对话。

## 验证

- 后端：67项测试通过，涵盖原有任务工作流、离线负例、范围与重启继承、跨语言语义模型替身、全文末章覆盖、逐字引用与支持检查、比较、计划确认、固定复习快照，以及会话隔离。
- 前端：27项测试通过，涵盖协议、动画状态、双窗口引用/警告/范围保留、历史恢复、草稿同步、超时和旧请求处理。
- TypeScript检查、Vite前端与Electron主进程构建通过。
- 使用HTTP测试传输验证Embedding以字符串发送，批次为10/10/3，不调用真实提供商。
- 浏览器实际检查：上传TXT、自动全文导览、无关“火星”问题返回资料不足、从桌宠提问同步到主窗口、从桌宠引用打开原文。

默认关闭真实模型连接。真实API的可用性、费用、回答准确率及语义阈值尚未用提供商实测；测试替身不代表真实模型效果。原生Electron窗口的置顶/拖动/重开仍需目标系统验收。Windows启动脚本未在Windows环境运行。

## 运行与数据

见根目录README。启动器检查后端协议版本，遇到旧后端占用8000端口时给出提示。数据库迁移使用新增表/新增列保留旧数据；已有复习题不会在后台被改写。切换向量模型需重新索引。重新索引原子替换片段并清除旧摘要缓存，历史引用快照仍保留。

RAG、Agent规划与意图识别统一读取模型配置，结构化输出使用兼容工具调用。百炼示例保留在`.env.example`，用户可以后再填写。图片字节与远端基线一致，无需重新上传。
