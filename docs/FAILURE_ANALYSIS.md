# 失败案例与改进记录

记录易复现的误判，便于回归。优先修意图优先级与实体归一，而不是堆新模块。

## 意图 / 路由

| 现象 | 根因 | 修复 |
|------|------|------|
| 「我需要进行30s专注」被当成复习作答 | 等待题时 `chat` 一律批改；专注正则只认「专注 N 分钟」 | 支持秒/语序；`resolve_turn`：命令 > 答题 |
| 「三十秒专注」语音识别后仍不启动 | 中文数字未归一 | `normalize_zh_numerals` → `30秒` 再解析 |
| 到点提醒带出整道复习题 | 把 `next_step.suggestion` 拼进气泡 | 气泡只保留「时间到～」 |
| 等计划目标时说「开始专注」却写成 goal | `pending_plan` 抢在 explicit 命令前 | pending 仅当 `direct.action=='chat'` |

## 检索 / 复习

| 现象 | 根因 | 修复 |
|------|------|------|
| 小测出现无关「叶子节点」等内置题 | 有资料时仍回落内置题库 | 材料优先出题与评分点 |
| 社交句「你好」被批改 | 等待态捕获过宽 | 社交短句与问题句不进入 `review_answer` |

## 回归入口

- `tests/test_dispatch.py`：优先级与中文时长
- `tests/test_intent.py`：明确命令路由
- `tests/test_review_grading.py`：材料评分
